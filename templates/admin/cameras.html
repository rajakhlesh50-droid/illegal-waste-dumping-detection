Laptop Hotspot Setup Guide (Laptop me Internet + Phone Camera Connect):
  1. Laptop Hotspot ON karein: Laptop me Win + A dabayein ya Settings → Network → "Mobile Hotspot" ko ON karein (Laptop Wi-Fi internet chalu rahega).
  2. Phone ko Laptop se jodein: Mobile phone ka Wi-Fi kholein aur Laptop ke Hotspot Wi-Fi network se connect karein.
  3. IP Webcam start karein: Phone me IP Webcam app kholein, sabse niche scroll karein aur "Start server" dabayein.
  4. Auto-Connect: Yahan upar "Auto-Detect Phone (Laptop Hotspot)" button dabayein, ya phone par dikha IP (jaise http://192.168.137.xxx:8080) paste karke Save karein!
